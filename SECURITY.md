# Security

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report it privately through GitHub: on the
[Security tab](https://github.com/skaragianis/lsty/security), choose
**Report a vulnerability**. Don't open a public issue.

Include the lsty version, your operating system, and the steps that show
the problem. The report and answer stay private until a fix is out.
